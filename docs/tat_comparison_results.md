## 🔍 Latency Analysis & Observations

- **Local Inference (Gemma via Ollama)**:
  - **Network Overhead**: Zero network latency since inference executes entirely on local hardware (`localhost:11434`).
  - **Model Load Time**: If the model is already loaded in RAM/VRAM, TAT depends strictly on token generation speed (`eval_duration`) and prompt processing.
  - **Multimodal & Tool Calling**: In the combined scenario, the model must decode the image and evaluate the tool schema in the same pass, so TAT reflects both image-encoding and reasoning/tool-selection cost together.

- **Cloud Inference (Gemini 2.5 Flash API)**:
  - **Network Overhead**: Includes HTTP request/response round-trip latency to Google Cloud servers.
  - **Time-to-First-Token (TTFT)**: Gemini Flash is highly optimized for low-latency cloud responses, often matching or beating local hardware depending on local GPU capabilities.
  - **Multimodal Payload**: In the combined scenario, the base64 image payload and the bound tool schema are both sent in a single request, adding to upload size and server-side processing time.
